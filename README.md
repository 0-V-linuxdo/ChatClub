# ChatClub 2.0（净室重写）

只依据功能规范（plugin-spec v1.3 + v2）从零写成的、一切皆插件的 ChatClub 2.0。

## 目录

- `extension/`：构建好的扩展，浏览器里“加载已解压的扩展程序”选这个文件夹即可。
- `src/`：源码。`kernel/` 是插件内核，`plugins/` 下每个文件夹是一个插件（`order.json` 定义加载顺序）。
- `scripts/build.mjs`：`npm run build` 生成 `dist/extension/`（与 `extension/` 相同）。
- `test/`：`npm test` 运行单元测试。

## 当前进度（验收版 1）

已完成：插件内核与设置、外观/主题/自定义 CSS、快捷键、顶部栏、工作区（分组、标签、布局、会话恢复、标签页侧栏、标签搜索）、输入框（发送、图片、占位文字、搜索模式）、新建对话、提示词库、提示词优化、API 服务商、Summary（采集、复制提取、面板、站点配置）、Pocket 收藏、记录全文、发送历史、分享（长图 / 文字）、各站点适配。
